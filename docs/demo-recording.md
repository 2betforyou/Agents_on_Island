# README 데모 영상 촬영 가이드

두 README의 대표 GIF와 동작별 MP4는 실제 SwiftUI 화면을 샘플 데이터로 렌더링합니다. Xcode와 FFmpeg가 설치된 Mac에서 `bash Scripts/readme-demo.sh`를 실행하면 대표 GIF와 호버·대시보드·완료·Option 숨김·설정 영상이 갱신됩니다. 캡처할 때 애니메이션을 32배 느리게 진행해 중간 자세를 샘플링한 뒤, 원래 동작 속도가 되도록 120fps MP4로 인코딩합니다. GIF는 프레임 간격을 20ms로 맞춥니다.

아래는 에이전트가 작업을 시작하고 완료하는 흐름까지 보여 주는 별도 영상을 촬영할 때 참고할 가이드입니다.

작업 화면의 실제 응답을 다시 촬영하려면 Claude Code에 로그인한 상태에서 `bash Scripts/readme-demo.sh --live-workspace`를 실행합니다. 샘플 폴더의 터미널에 예시 질문 한 건을 입력해 Claude Code의 텍스트 응답을 캡처합니다. 답변 대기 구간은 짧게 편집합니다.

15~25초 동안 에이전트를 돌려 두고 다른 일을 하다가, 섬에서 완료를 확인하고 세션으로 돌아오는 흐름을 보여 줍니다.

## 준비

- 바탕화면 정리: 개인 파일·폴더·이메일·메신저 창을 닫습니다. 메뉴 막대의 개인 항목(계정, 메일 알림 등)도 숨깁니다.
- 방해 금지 모드를 켜서 다른 알림이 끼어들지 않게 합니다.
- 샘플 프로젝트를 씁니다. 예: `~/Projects/my-app`에 작은 웹 앱을 하나 만들고, 실제 회사·개인 저장소는 쓰지 않습니다.
- Agents on Island에서 언어를 영어로 설정하고 사용량과 작업 중 표시를 켭니다. 최근 활동에는 샘플 프로젝트의 기록만 보이게 합니다.
- 터미널 글자 크기를 14~15로 키우면 영상에서 더 잘 읽힙니다.
- Claude Code 요청은 10~20초 안에 끝나는 작은 작업으로 고릅니다. 예: "Add email format validation to the login form and run the tests".

## 장면 (총 20초 안팎)

| 시간 | 화면 | 보여 줄 것 |
|---|---|---|
| 0–3초 | 대기 중인 노치 | 노치 양옆의 사용량(숫자·링) |
| 3–6초 | 노치에 마우스 올림 → 미리보기 | 프로젝트, 입력창, 최근 활동 |
| 6–10초 | Start here에 요청 입력 → ↩ | 바로 Claude 세션 시작 |
| 10–12초 | `⌃⌥Space`로 접기 | 노치가 작업 중(`•••`)으로 바뀜 |
| 12–17초 | 다른 앱(브라우저·에디터)에서 작업 | 노치에 작업 중 표시가 계속 보임 |
| 17–19초 | 완료 배너가 노치 아래로 내려옴 | "Finished · Claude Code · my-app" |
| 19–22초 | 배너 클릭 → 작업 화면 | 결과가 담긴 터미널 |

시간이 길어지는 구간(Claude가 일하는 동안)은 편집에서 잘라 내거나 2배속으로 줄입니다.

## 녹화

1. `⌘⇧5` → **선택 부분 기록**을 고르고, 노치를 포함한 화면 위쪽 가운데를 1280×800 정도로 잡습니다(노치와 작업 화면 전체가 들어가게).
2. **옵션 → 마우스 클릭 보기**를 켭니다.
3. 녹화한 `.mov`는 QuickTime에서 앞뒤를 자릅니다(**편집 → 다듬기**).

## README에 넣기

- 가장 쉬운 방법: GitHub에서 README를 편집하면서 `.mov`/`.mp4` 파일을 끌어다 놓습니다. GitHub이 영상 주소를 넣어 주고, README에서 바로 재생됩니다(10MB 이하 권장, 최대 100MB).
- 영상은 상단 호버 GIF 아래에 추가합니다.
- 영어 README와 한국어 README에 같은 영상을 써도 됩니다(화면이 영어라도 흐름은 같습니다). 한국어 화면으로 따로 녹화해도 좋습니다.

## 다시 확인할 것

- 영상 속 터미널·파일 경로·브랜치 이름에 개인 정보가 없는지
- 메뉴 막대에 개인 항목이 보이지 않는지
- 사용량 수치가 실제 계정 값이어도 괜찮은지(괜찮지 않으면 사용량 표시를 끄고 촬영)
