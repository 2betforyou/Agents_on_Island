# v0.1.5 GitHub 릴리즈 준비

1. 버전 변경과 릴리즈 노트를 검토하고 릴리즈에 포함할 소스 커밋을 push합니다.
2. [Agents on Island의 Releases](https://github.com/2betforyou/Agents_on_Island/releases)에서 새 릴리즈 초안을 엽니다.
3. 태그 `v0.1.5`를 만들고 배포 ZIP을 빌드한 소스 커밋을 대상으로 선택합니다.
4. 제목은 `Agents on Island v0.1.5`로 지정합니다. [릴리즈 노트](v0.1.5.md)의 첫 제목을 제외한 본문을 설명에 붙여 넣습니다.
5. 아래 두 파일을 첨부합니다.

   - `Dist/Agents_on_Island-0.1.5-macOS.zip`
   - `Dist/Agents_on_Island-0.1.5-macOS.zip.sha256`

6. **Set as the latest release**를 선택하고 내용을 확인한 뒤 공개합니다.

다운로드 파일은 ZIP과 체크섬을 같은 폴더에 둔 뒤 `shasum -a 256 -c Agents_on_Island-0.1.5-macOS.zip.sha256`으로 확인할 수 있습니다.
