# v0.1.4 GitHub 업로드

1. 변경 사항을 검토한 뒤 직접 커밋하고 push합니다. 이 준비 작업에서는 커밋·태그·원격 릴리스를 만들지 않았습니다.
2. GitHub 저장소의 **Releases → Draft a new release**를 엽니다.
3. 태그는 `v0.1.4`을 새로 만들고, 방금 push한 커밋이 있는 브랜치를 선택합니다. 기존 태그는 옮기지 마세요.
4. 제목은 `Agents on Island v0.1.4 — Your agents, each on its own island`를 사용합니다.
5. [v0.1.4.md](v0.1.4.md)의 첫 제목 줄을 제외한 나머지를 설명란에 붙여 넣습니다.
6. 다음 두 파일을 첨부합니다.
   - `Dist/Agents_on_Island-0.1.4-macOS.zip`
   - `Dist/Agents_on_Island-0.1.4-macOS.zip.sha256`
7. 로컬 ad-hoc 서명·미공증 빌드라는 안내를 유지하세요. Apple 공증이나 자동 업데이트를 지원한다고 표시하지 마세요. **Set as the latest release**를 선택하고 직접 Publish release를 누르면 됩니다.

ZIP을 다시 만들 때는 `bash Scripts/package.sh`를 실행합니다. 같은 이름의 ZIP이 이미 있으면 덮어쓰지 않으므로 기존 파일을 먼저 다른 위치로 옮기세요.

서명·공증된 배포 파일이 필요하면 Developer ID Application 인증서와 notarytool 프로필을 준비하고 `Scripts/release.sh`를 사용하세요. 이 경우 설치 안내와 첨부 파일명을 실제 결과에 맞게 수정해야 합니다.
