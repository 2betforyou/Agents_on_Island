# Agents on Island v0.1.5

- 외장 화면에서 에이전트가 하나일 때 중앙 아일랜드가 넓어지는 배치를 수정했습니다.
- 합쳐진 아일랜드의 중앙에 마우스를 올리면 전체 대시보드, 양끝에 올리면 에이전트 미리보기가 열립니다.
- 최소화 화면과 작업 화면 하단의 숫자를 남은 5시간 한도로 통일했습니다. 주간 한도는 호버 미리보기에서 확인할 수 있습니다.

## English

- Fixed the centered layout when a single agent is visible on a display without a notch.
- The center opens the dashboard on hover. Either end opens the agent preview.
- The collapsed islands and workspace footer show the remaining five-hour quota. Weekly quota is available in hover previews.

Requires an Apple silicon Mac with macOS 14 or later. The ZIP contains an ad-hoc signed build.
